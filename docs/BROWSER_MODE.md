# 网页模拟模式：需求、实现与边界

## 目标与优先级

P0：在现有设备工作台中输入 HTTP/HTTPS 地址，按指定的 Duo 视口尺寸加载可交互网页；保留全部六种设备场景、开合进度、镜头与外观控制。顶部两张模式卡明确区分“上传图片并导出”与“输入网站并预览”。切换模式保留截图、场景、构图及网址配置。旧项目默认截图模式。

P0：提供不依赖第三方的本地响应式演示页，支持按钮、输入、滚动及当前 CSS 尺寸展示。输入域名默认补 HTTPS，拒绝脚本、文件、数据协议及携带账号密码的 URL。刷新重新创建网页文档。禁止递归嵌入本工具同源地址；内置演示单独提供入口。

P0：不能承诺“任何网站”。目标网站的 frame-ancestors / X-Frame-Options、HTTPS 混合内容、第三方 Cookie 与登录规则仍由浏览器执行。展示排查说明及原站打开入口，不使用代理绕过。iframe load 事件不代表加载成功，因此状态提示为“已尝试打开”。

P1：1× / 2× / 3× 像素比例控制实际 CSS 视口，默认 3×。比例只用于计算 iframe width/height，不伪造设备 DPR、UA、Safari 或折叠 Web API。独立的预览画布控制构图，不改变网页排版尺寸。

P1：自动保存网页配置到现有 IndexedDB 和项目文件。截图导出入口在网页模式改为“制作截图”，引导切回上传；导出函数同时阻止直接导出网页，避免错误导出底层示例图。

## 交互与状态

- 顶部“截图制作 / 网页模拟”切换 workspace；原“展示图 / 开合动画”是独立的 mode，在网页模式命名为“网页交互 / 开合演示”。切换 workspace 暂停播放，保留其他配置。
- 网站地址提交后标准化并刷新内外屏。网页主动跳转不会回写地址栏：跨域下无法读取最终 URL，也不提供假后退/前进按钮。
- “操作网页”允许 iframe 点击、输入、滚动；“旋转设备”禁用其指针事件，将拖动交还设备画布。外部开合与镜头控件始终有效。
- iframe 在镜头、进度变化期间保留文档；离开网页模式会卸载网页，再进入会重新加载。iframe 内部表单与滚动位置不保存进项目。
- 静态场景调整开合进度继续保持所选场景；播放沿用现有 timeline，并展示自由开合动画。
- 网站通常需要联网；已上传截图的编辑和导出仍完全本地。

## 复用与渲染

复用 Project、DeviceRenderer、真实设备骨骼、动画进度、相机、场景控制与历史记录。浏览器配置集中于 Project.browser，投影数学集中于 lib/browser.ts，地址与操作控件集中于 BrowserControls。

网页是实际 DOM iframe，不能被直接采样成 WebGL 纹理。渲染采用与 WebGL 同相机的 CSS matrix3d 投影，通过 skinned screen mesh 的正面多边形裁切并遮蔽前方外屏，保留设备边框。开合演示使用既有固定内容平面，静态姿态跟随实际骨骼平面；外屏翻转校正避免镜像字。模糊使用 CSS blur，属于网页模式近似效果，不声称与截图 shader 逐像素一致。

完全展开时内屏使用一个文档。静态弯折姿态将内屏分成两片独立 iframe，显示同一 URL 的对应区域。跨域 DOM 不可读取，分片以及内外屏之间不能同步点击、滚动、导航或登录；该限制在网页帮助中明确显示。此模式用于视口排版及设备形态预览，不能代替真实设备上的连续折叠浏览器交互验证。

## 安全与部署

所有资源来自静态 dist，Cloudflare Pages 无 Functions、密钥或代理。CSP frame-src 允许 HTTP/HTTPS 目标；frame-ancestors 允许本工具同源以容纳演示 iframe。父页面其余脚本/网络策略保持原限制。iframe 使用 sandbox，允许网站脚本、表单和原站弹窗，禁止顶层导航；Referrer-Policy 为 no-referrer。目标网站自身的嵌入限制不受父页面设置影响。

## 后续建议

可为愿意配合的目标网站提供 opt-in postMessage 桥接，用严格 origin 校验同步滚动、导航和状态；通用跨域 iframe 无法实现这一点。网页截图/视频如需完整导出，需要用户授权的屏幕捕获或后端浏览器渲染，另行设计权限与隐私流程，不纳入当前纯前端跨域功能。

## 2026-09-11 修正：侧边覆盖与连续屏幕

复现命令：`npx playwright test tests/browser-edges.spec.ts`。修复前，90% 展开时左边缘的网页横向坐标为 -0.0231（超出 iframe），同时内屏存在两个独立裁切轮廓。

原因一：网页采用有限矩形平面，缺少截图 shader 的侧向延伸；现在在固定的上下内容边界内扩展横向投影覆盖范围，保持 CSS 排版尺寸不变。DOM 页面通过横向投影填满玻璃，与截图的边缘纹素钳制实现不同。

原因二：按原始顶点 X 坐标拆分轮廓遗漏了铰链条带，仅在 99% 以上合并；现改为追踪可见网格三角形的外边界，既覆盖铰链，又保留半展开时的凹形轮廓，避免遮盖机身。

网页与截图使用同一个 `screenMotion` 开合曲线。网页以局部 backdrop-filter 模糊活动一侧，右半屏保持清晰；手动拖动与播放均使用同一效果。网页 DOM 合成和截图 WebGL shader 仍是两种实现，不保证逐像素一致。

界面改为顶栏工作区切换，删除大幅宣传标题、重复提示、常驻请求状态和网页模式下的截图页面管理。加载状态保留屏幕阅读器通知，不能嵌入及导出说明保留在展开帮助中。
