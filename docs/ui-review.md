# Duo Studio 界面复审与改版

2026-09-12 · Hallmark redesign · 当前单页编辑器

## 复审结论

原界面中，模式切换、场景、上传入口和导出操作缺少明确的视觉层级；预览区域高度让播放控制落到页面底部；基础模式和高级模式的文字、圆角、间距也不够统一。

本次采用内容优先的工作台布局，参考 [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) 的层级与控件分组原则。设备预览是页面主体，界面使用原生系统字体、中性背景及蓝色主要操作。

## 已实现

- 顶部将项目身份、两种工作模式、GitHub / 主题切换分组。基础模式的切换器居中，高级模式为项目操作预留空间。
- 六个场景始终展开，使用设备图标和简短标签；导出为主要操作，高级设置保持次要且默认收起。
- 截图上传收为可展开入口，网页模式沿用同一位置提供网址输入。
- 播放、折叠滑块和角度合并成紧凑控制栏。基础模式预览按可用视口限制高度。
- 统一浅色 / 深色语义色、间距、圆角、焦点指示和按压反馈。保留不固定的页头、无页脚及全屏入口。
- 320px 下场景分为两行；375px 起保持六个场景一行。顶部在窄屏分为两行。

## 实现边界

`tokens.css` 管理语义化设计变量，`src/studio.css` 作为现有样式之后的设计层。`App.tsx` 仅为页头增加分组容器，沿用原有组件、文案、项目状态、设备渲染和网页捕获逻辑。没有新增字体或运行时依赖，也没有删除生产文件。

采用原生系统字体和保留工作台结构，是为了遵循用户明确的 Apple 风格及已有功能要求；没有为满足风格轮换而改成营销落地页。设备模型为真实交互内容，不是装饰性设备框。

## 验证

- 视觉检查：桌面浅色、深色、网页模式、高级模式，以及 320 / 375 / 414 / 768px 基础模式。
- 响应式交互测试覆盖 320 / 375 / 414 / 768 / 1440px，两种工作模式均无横向溢出，模式切换和顶部操作不重叠。
- 回归：高级模式切换保留 iframe 内容；原生全屏及 Escape 回退正常；折叠进度保留所选场景。
- 网页捕获回归验证内屏左右内容及捕获标记。生产构建和单元测试另行运行并记录在本次任务结果中。
