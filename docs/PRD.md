# Duo Studio 产品需求文档

版本：1.0 · 2026-09-10 · 本次交付范围 P0 + 下述明确列出的 P1。状态以 VALIDATION.md 的实测记录为准。

## 1. 产品定义与边界

面向独立开发者、设计师和发布运营，在没有 iPhone Duo 真机的情况下，将已准备好的 App 多形态界面生成设备预览、PNG、开合动画等展示素材。完整静态网站，Cloudflare Pages 仅分发文件，无 Functions、账户、数据库服务、上传接口或远程转码；所有用户素材、自动保存、编码均在浏览器完成。

输入是设计稿/模拟器/真机截图，不自动重排 UI，不运行 iOS App，不证明真实适配。不将渲染的设备动画标为 App Store App Preview。采用官网公开设备网格、贴图与 Slider 骨骼动画，屏幕替换与模糊效果在本地渲染；不声称是硬件仿真器。素材规格与真实运行适配分别判断。

成功任务：用户打开页面 → 了解示例 → 上传外屏和内屏 → 拖动开合 → 调整背景与镜头 → 导出 PNG 和动画 → 下载项目 → 重开后恢复。

## 4. 工作区与具体交互

### 4.1 初次进入

默认进入“展示图”，加载用户提供的 EchoPod 内外屏截图，并明确标注“EchoPod 示例”。不把演示槽位标成用户已上传。首次无需上传即可拖动开合；提供“上传你的截图”入口。示例可导出，但文件名带 demo；关闭示例后缺失槽位显示中性占位，正式导出阻断。示例开关是项目级显式选择。

顶栏：品牌/项目名、保存状态、撤销/重做、导入与保存项目、导出。
左栏：页面列表、添加/复制/删除、场景列表、素材覆盖状态。
中间：模式切换、画布、场景标签、拖动旋转与重置镜头、播放/开合控制。
右栏：素材管理、等比方式与裁切、设备与背景、动画参数。
底部：本地处理状态与输出规格。窄屏按画布→场景与页面→属性流式展示，无水平溢出；所有功能保留。

### 4.2 页面和场景

一个项目有 1–20 个页面，内嵌图片编码总量最多 75 MiB，以保证导出的项目能再次导入；页面有独立名称、标题、副标题和五个槽位。添加创建空页面，不伪造上传；复制保留素材和文本；删除需要应用内确认，最后一个页面不可删除。切换页面保持全局镜头/背景/动画设置。页面变更可撤销。

选静态场景设置其预设开合角和方向并停止播放；选“开合”使用手动进度。拖动开合滑杆只改变角度，保留当前场景与姿态。切换模式不丢失图片、文字和镜头；进入动画模式选择开合场景。播放从当前播放位置开始，结束停住；再次播放结束位置时从头开始。手动定位停止播放。预览与视频共享同一时间函数。

### 4.3 导入截图

点击素材槽位或拖入单张 PNG/JPEG/WebP。单文件最多 20 MiB，最多 4096 px 边长、1600 万像素；格式、尺寸和解码都必须成功后才替换旧图。对不合比例的图片给出提示，不拒绝合法图；新建页面默认 cover 等比铺满，不拉伸；旧项目保留已保存的 fit 设置。多图误拖时提示一次仅处理一张。SVG/GIF/视频暂不作为素材接收。

用户可显式选择“设计稿/模拟器/真机”来源。素材卡显示文件名、原始尺寸和推荐尺寸。小于目标尺寸时提示导出不会增加真实细节。移除只清空当前槽位，可撤销。上传过程中禁用同槽操作；失败保留旧图并可重试。异步解码按目标页面 ID 写入，避免切页后贴错页面。

完整显示（contain）：保持比例，空白区为深色屏幕底色。裁切填充（cover）：填满屏幕，超出边界裁掉，允许 X/Y 位置 0–100% 和 1–2×缩放；切回 contain 时隐藏裁切控制，仍保存其值。重新上传保留用户的裁切偏好。

上传区提供“外屏截图 / 内屏截图”两个直接入口，同时保留横向、竖向、坐姿和站立的场景选项。没有独立外屏图片时，从当前页面内屏原图截取左侧 50%：优先横向，其次竖向，最后坐姿。再使用外屏自己的 fit / X / Y / zoom 设置绘制，避免取到右半边。明确显示自动取图来源。

独立外屏优先；移除独立外屏后恢复自动取图；内屏替换或移除后重新解析来源。自动取图不复制成新 asset，保存/导入仍保存原始图片和各屏显示设置。缺图判断认可自动外屏，关闭示例后允许预览及设备 PNG/动画导出。严格尺寸纯 UI 导出继续要求独立上传的原始截图。

### 4.4 3D 渲染

实体由两半机身、铰链、完整内屏的左右纹理切片和单独外屏组成。内屏截取来自同一张纹理，不能将同一张截图重复贴在两半。横竖版纹理先转换到物理屏幕坐标。折叠开合 0–100% 映射为本工具的闭合–平展，不声称系统事件角度。

拖动画布改变镜头方向，松手提交到可撤销状态；保留独立水平/俯仰滑杆供键盘使用。重置恢复默认相机和缩放。静态和导出调用同一个渲染器；导出独立 WebGL 上下文，不改变屏幕上的编辑状态。WebGL 初始化失败显示可读错误，仍允许保存项目。

### 4.5 动画

预设 open/close/loop。动作时长 2–10 秒（不含停留）；起始/结束停留各 0–2 秒。loop 在动作区间内前半展开后半合上。缓动 linear 或 ease-in-out。30 fps；GIF 使用 12 fps 和较小画布以限制资源。静态截图仅定义设备内外屏内容，不创造 UI 自动重排或模拟系统转场。

视频逐帧按时间计算开合和相机，编码帧数为 ceil(总时长×fps)。进度显示百分比；导出时锁定编辑操作；取消应丢弃部分文件并释放编码器/渲染器。MP4/AVC 与 WebM/VP9 在导出前检测；不支持不能伪装成成功下载，建议其他格式。GIF 不依赖视频编码器。

### 4.6 展示图

展示画布有横版 1600×1000、竖版 1080×1350、方形 1200×1200；透明背景仅对展示 PNG 生效。背景提供纸白、雾灰、浅蓝、暖沙、深夜。设备机身银色/深色。缩放范围保持在画布内的安全构图范围。

上架套图入口、排版编辑与合成已删除。旧项目的 store 模式在解析时迁移为 image，素材与历史元数据保留。展示图仍提供横版、竖版与方形输出。

纯界面导出：选择一个素材槽位，必须是真实上传；严格要求其宽高等于目标推荐尺寸，直接输出解码的界面 PNG，不叠加机身、标题或重采样成虚假的精确截图。异常给出具体尺寸提示。

### 4.7 批量导出

遍历全部页面的五种静态场景，输出有真实素材的场景及自动生成的外屏；示例不计入批量覆盖。ZIP 带 manifest.json：页面、场景、素材来源、派生来源与 left-half 裁切标记、原始尺寸、输出尺寸、规格版本；使用有序序号与净化文件名。无素材时阻断并说明。逐张渲染并打包；每一项推进进度，随时可取消；项目最多 20 页限制内存。

### 4.8 保存恢复

浏览器 IndexedDB 保存整个项目，去抖保存，不使用易溢出的 localStorage。自动恢复优先于初始示例；恢复完成前不写默认值。存储不可用/配额不足时显示“自动保存失败，请保存项目文件”，不能显示“已保存”。导出 JSON 包含所有图片 data URL，下载后可离线重新导入。清浏览器数据可能移除自动保存，因此显式保存入口常驻。

JSON 导入最大 80 MiB，schemaVersion=1；校验字符串长度、枚举、数值上下界、页数、唯一 ID、有效 activePageId、图片 data URL MIME。进一步实际解码图片并核对元数据，任何失败都不替换现有项目。导入成功可撤销；对象中的未知字段不执行，不加载外部 URL。

撤销重做保留最多 30 次文档快照；排除播放过程、导出进度和通知。滑杆一次拖动提交一次，避免历史快速填满。新编辑清空重做栈。

## 5. 非功能需求与质量门槛

- 用户素材无网络上传；字体、图标与脚本从本站提供，不引用远程示例或 Apple 资源。
- 构建产物只有静态 HTML/CSS/JS；无 API key、Node 运行依赖、服务器路由。
- WebGL 画布按容器尺寸和不超过 2 的像素比渲染；非播放时仅在数据改变时重绘。
- 图片缓存有界，替换/页面切换清理旧纹理；销毁 WebGL、对象 URL 和编码任务。
- 键盘可访问按钮、文件输入和滑杆；对话框捕获焦点、Escape 关闭/取消，关闭后恢复焦点；通知使用 live region。
- 320/375/414/768/1440 px 无横向页面溢出；移动端可完成图片上传、场景选择、保存和导出。
- 无网络时已加载页面仍能完成本地编辑/导出；首次访问和未缓存刷新需要静态主机，不承诺 PWA 离线安装。
- PNG 验证尺寸/透明/非空；MP4/WebM 验证容器、时长、帧画面；GIF 验证可解码和多帧；ZIP 验证目录与 manifest。

## 8. 实现补充

视频画布按所选比例等比限制最长边 1280 px（偶数尺寸），GIF 最长边 640 px。PNG 渲染使用最高 4096 px 的纹理准备上限，交互预览使用 2048 px 上限；两者保持同一构图。内外屏几何宽高比直接依据截图比例计算。自动保存状态更新不属于导出项目快照，不能取消正在编码的任务。

## R03 开合投影交互补充（2026-09-10）

- 自由开合保持右半部的空间位置和镜头构图固定，仅左半部按官网 `Slider` 骨骼动画展开/合上。不能按每帧机身包围盒重新居中。
- 外屏图像保持正立和固定高度，以铰链侧为横向锚点。左半部玻璃转动时，按固定图像平面采样，不将文字随屏幕一起剪切拉伸。
- 屏幕垂直侧缘使用图片边缘延展，不出现额外黑条；玻璃超出图像上下边界的区域显示黑色，并由玻璃透视形成三角形边界。黑色区域需与图像边缘一起平滑模糊，不能以整块侧屏压黑代替。
- 模糊和亮度由开合进度及投影图像位置决定；暂停、拖动和导出到同一进度应得到一致画面。完全闭合的外屏、完全展开的内屏恢复清晰。
- 切换静态姿态仍按该场景构图居中，使用对应截图槽位及横竖方向。开合固定构图不改变静态上架图的居中行为。
- PNG、GIF、MP4、WebM 共用投影逻辑；纯 UI PNG 保留原始界面，不应用设备投影或模糊。
- 验收：右屏顶点五角度偏移小于 0.5 像素；双向开合的水平标记保持水平；黑区位于不透明玻璃内部；清晰区域不被清零；关闭恢复原画；同尺寸换图不丢失内容。

## EchoPod 默认示例（2026-09-11）

默认内屏 2670×1878、外屏 1398×2034，使用用户提供的原始 PNG 并随静态站点发布。根据画布横竖比例选择对应示例，完整显示，不生成不存在的 App 布局。应用介绍来自 https://echopod.clothpath.com/：播客/YouTube/个人媒体语言学习，逐词同步字幕、查词、翻译和 AI 语法讲解。

示例与上传素材隔离，上传优先；移除用户图片且开启示例后恢复内置图片。关闭示例后的缺图阻断、自动外屏和 ZIP 的真实素材规则保持有效。旧版完全未修改且没有上传素材的旅行示例页面更新为 EchoPod 文案；用户页面不覆盖。

## 网页模拟模式增量

新增与截图制作平级的网页模拟工作区，复用设备与动画控制。完整优先级、交互状态、前端实现与 iframe 限制以 [BROWSER_MODE.md](BROWSER_MODE.md) 为准。截图制作继续负责图片/视频导出；网页模拟负责允许嵌入站点的实时视口预览。
