## 视觉检查与已修复问题

1. 早期内屏中缝过宽：调整内侧贴图位置，保留细缝，避免把同一张图重复贴到两个屏幕。
2. 站立姿态倒置：重新推导外屏纹理旋转和倒 V 空间姿态；现在文字正向、可见支撑关系；不活跃内屏调暗。
3. 连续重绘出现中心偏移：在计算包围盒前更新父节点世界矩阵。新增像素一致性回归测试。
4. 自动保存刷新导致视频被取消：导出会话使用固定文档快照，生命周期不再依赖每次父组件重绘。MP4/WebM/GIF 回归通过。
5. 长标题挤占设备区：按排版可用高度逐步缩小字号，保留换行及标题/副标题完整性。
6. 重复图片伪造不同尺寸可跳过校验：解码结果缓存为真实尺寸，并逐槽核对元数据。
7. WebKit 关闭对话框后焦点未返回：统一按钮点击焦点行为，Escape 关闭与返回触发按钮回归通过。
8. 素材总量限制：累计编码最多 75 MiB，避免生成无法再次导入的便携项目。

静态产物实拍保存在 `docs/screenshots/`：工作台、闭合、横屏、竖屏、坐姿、站立。原始 E2E 过程截图和导出示例保存在被 git 忽略的 `test-results/`，重跑会替换。

## 已知限制与待验证项

- 设备几何及动画来自 Apple 官网；本地材质和屏幕效果并非官网完整引擎，不是真实硬件模拟器或适配验证工具。
- 未在真机 Safari/iOS/Android 上测试；视频编码取决于系统与浏览器能力，界面有检测和格式替代。
- 不含录屏输入、音轨、自动 UI 重排、多语言变体、在线分享；详见 PRD 后续优先级。
- 首次访问/未缓存刷新仍需要网络；不是可安装的离线 PWA。
- 极限 20 页/75 MiB 项目未在低内存移动设备做压力测试；允许取消，失败保留项目。
- 构建提示 Mediabunny 延迟加载的视频模块超过 500 kB（gzip 约 183 kB），以及 Zod 上游注释优化提示；不影响类型检查或静态运行，视频模块仅在需要时加载。
- 没有创建或部署 Cloudflare Pages 云端项目。已验证静态产物和 CSP，云端账户/域名/最终 Pages 响应需实际部署时再核验。
